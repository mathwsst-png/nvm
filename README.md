# NVM.X

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/mathwsst-png/testing/refs/heads/main/nvmx"))()
```

Ganti `mathwsst-png/testing` di URL dan di variabel `repository` pada file `nvmx`.

- `nvmx` : loader (cek commit terbaru, lalu jalankan `nvmx-main.lua`)
- `nvmx-main.lua` : script utama (Farm, Clear World, Farmer, Lahan, Penjaga, Pengaturan, Koneksi, Discord)
- `nvmx-diagnose.lua` : diagnosa baca-saja
